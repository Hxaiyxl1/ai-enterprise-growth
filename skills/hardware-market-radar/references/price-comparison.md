# 价格匹配与比较

## 一、先匹配，再比较

比较前逐项核对，任一不一致即判「不可直接比较」：

- 品牌、型号、店铺、平台、货币、计价单位
- 负载、臂展、重复定位精度、轴数、防护等级、控制器型号、末端夹具（机器人必查）
- 是否含立杆、打印、配件、安装、校准
- 单件或批量、起订量、价格类型、地区、税费、运费
- 优惠资格、有效期、是否存在个性化价格

规格或购买条件不同，**并列展示两条原价与条件，不计算涨跌**。典型陷阱：把「本体价」和「本体+控制柜+示教器」的套装价并列，或把裸机价与含集成调试的报价并列。

## 二、价格类型分开存

同一商品有多个公开价格时，分别保留：页面标价 / 可核实的条件价 / 数量阶梯价 / 询报价。每条记录同时保留原始价格文字与结构化金额。

页面价格只能证明该页面在该时点展示过这个价格，真实成交需独立证据。

## 三、只有可比才计算

```
变动额 = 本期价 − 上期价
变动率 = 变动额 ÷ 上期价 × 100%
```

上期为 0、缺失或口径不同 → 变动率留空并说明原因。

## 四、变化归类（五选一）

| 类型 | 含义 |
|---|---|
| 常规标价变化 | 页面标价本身调整 |
| 促销变化 | 限时券、活动价带来的变化 |
| 购买条件变化 | 规格、套装、阶梯、运费税费条件变了 |
| 仅本期观测 | 无同口径上期数据，只建基线 |
| 未见可核验变化 | 已比对，价格未变 |

一条限时券不代表长期调价。下架、缺货、链接失效**单列**，不当作涨跌。

## 五、趋势线门槛

只有同口径、至少 3 个有效观测时点才画趋势线。少于 3 个点用条形图或表格并列，不画折线。

## 六、基线表 vs 变化表

- 首次采集：`品牌/型号｜渠道｜本期观测价｜规格与购买条件｜证据编号`
- 更新模式：`品牌/型号｜渠道及购买条件｜上期价｜本期价｜变动｜判断｜证据编号`

正文只放重点 3–5 条，其余进附录。每行必须显示价格类型与采集时间。
