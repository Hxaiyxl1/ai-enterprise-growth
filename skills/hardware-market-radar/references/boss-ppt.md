# 老板版 PPT 规范

## 一、总体

16:9 横版，白底，深蓝标题，灰色辅助信息，**橙色只用于关键变化和待决策项**。正文 8 页 + 证据附录，5 分钟能讲完。材料少时可合并第 6、7 页，**禁止为凑页数编造内容**。

每页只讲一个观点，正文 ≤3–5 条。标题优先写事实结论，例如「本期可比样本的降价主要来自限时券」，不写「价格分析」。

## 二、逐页结构

**P1 封面**：标题《XX 行业与竞品情报周报》；报告周期、重点地区、品类、数据截至时间；汇报人未知则省略。

**P2 结论与待决策**（最重要的页）
- 标题就是本期最重要的一句结论。首次采集可写「重点 SKU 价格基线已建立」，但只有确实建立后才能用。
- 三栏：本周变化 / 对我们的影响 / 建议动作，最多 3 条，每条带证据编号。
- 页底「本周需拍板」≤2 项，写清批准什么、多久验证、按什么标准判断。确无事项写「本周无新增决策事项」。

**P3 行业热点**：表列 `事件日期｜事件｜影响的产品或客户群｜证据`，≤3 条。计划、发布、生效分开写，每条都要说明与本业务的关系。

**P4 竞品价格**：机器人整机报价普遍「面议」，正文先区分「公开标价 / 渠道报价 / 需询价」三类，只有公开标价才能进变化表；首次采集出基线表。列见 `price-comparison.md`。正文 3–5 条，其余进附录。确实可比的变动才加颜色或箭头。

**P5 竞品营销**：选 2–3 家对照，列 `竞品｜主推产品｜公开营销动作｜成交方式｜策略判断及证据`。重点看短视频、直播讲解、批发阶梯、套餐、安装质保。

**P6 对我方影响**：≤3 条，每条「证据 → 影响对象 → 建议动作」。影响对象具体到客户群、品类、规格或渠道。标注已核验事实与待验证推断。

**P7 下周行动与审批**：≤3 项，列 `优先级｜动作｜建议负责岗位｜建议完成时间｜验收方式｜是否需要审批`。负责人未知写岗位，预算未知写「待核算」，不替公司承诺结果。测试要有比较基准——例如同一台协作臂分别做场景演示视频与参数讲解视频，记样本量与有效询盘后比较。

**P8 覆盖与下次观察**：实际检查的渠道/店铺/账号数、可核验 SKU 数、可比报价数；逐渠道标注已核验/部分核验/不可访问/未检查；下次优先补查 1–3 项及其影响哪个判断。

**附录 A1 价格明细**：证据编号、直达链接、平台、店铺、型号、规格、原始报价、报价条件、采集时间。
**附录 A2 热点与营销**：证据编号、发布主体、事件或发布时间、观测时间、链接、支持的事实。

正文每个编号都要在附录找得到，链接须可点击。用户提供的截图注明来源及原页面核验情况。

## 三、设计与排版

- 中文无衬线；正文 18–22pt，表格 ≥15pt；过长内容移附录。
- 原生可编辑文字、表格、图表，不用图片代替表格。
- 图表写清单位、日期、样本范围；同一张涨跌图只比较同口径报价。
- P2–P7 各配 1–2 句讲稿，优先放演讲者备注；讲稿讲影响与决策，不逐字念页面。

## 四、生成流程

使用当前环境可用的 PPTX 生成工具，核对页面边界、字体、页数及附录的证据编号。

避免用 `<b>` 等富文本标签，改用 `style={{ fontWeight: 'bold' }}`，否则 lint 报错。

## 五、命名

`<行业>行业情报周报_YYYY-MM-DD.pptx`，同目录放 `价格快照_YYYY-MM-DD.csv` 供下期比对。
