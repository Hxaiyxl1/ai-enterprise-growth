# 企业增长情报

来自企业增长陪跑实践的情报研究 Skill。采集行业动态、竞品公开营销动作、可比价格和真实客户评价，整理成可追溯的调研报告、复查底表与管理层汇报。

## 安装

把本仓库地址发给支持本地文件操作的 AI 助手，并告诉它「安装 skills/hardware-market-radar 目录中的企业增长情报 Skill」。保留目录中的参考资料和脚本。

## 使用

> 用企业增长情报 Skill 调研我的行业和竞品，整理最近 30 天动态，提供有直达证据链接的结论和下一步建议。
